# 🧮 Calculator Web Application

A simple, responsive, and interactive calculator built using **HTML, CSS, and JavaScript**.  
This project performs basic arithmetic operations with a clean and user-friendly interface.

---

## 📌 Overview
This project is created to practice front-end development skills and understand how HTML, CSS, and JavaScript work together to build real-world web applications.

---

## ✨ Features
- Basic arithmetic operations: Addition, Subtraction, Multiplication, Division, Percentage
- Clean and responsive design  
- Easy-to-use interface  
- Lightweight and fast performance  

---

## 🛠️ Technologies Used
- HTML5  
- CSS3  
- JavaScript (Vanilla JS)  

---

## 🎯 Purpose
To apply my learning of HTML, CSS, and JavaScript by building a simple calculator and implementing JavaScript logic in a real project.
## 📁 How to Run
1. Download or clone this repository  
2. Open the project folder  
3. Open `index.html` in your browser  
4. Start using the calculator
